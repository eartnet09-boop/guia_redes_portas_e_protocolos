# Política de segurança

Este repositório é material educacional e não recebe dados de telemetria nem opera serviços. CISA significa Cybersecurity and Infrastructure Security Agency (Agência de Segurança Cibernética e Infraestrutura dos Estados Unidos). Para comunicar uma vulnerabilidade no próprio conteúdo ou em sua cadeia de publicação, use a opção **Report a vulnerability** na aba **Security** do GitHub, quando disponível, ou abra uma issue sem incluir dados sensíveis.


Não publique credenciais, endereços internos, dados pessoais ou detalhes que exponham ativos de terceiros. Para incidentes em produtos citados neste guia, contate o fabricante e siga os canais oficiais de divulgação coordenada. Consulte o [catálogo CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) e os avisos do fornecedor para decisões de correção.
